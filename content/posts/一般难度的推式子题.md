首先我们有 $O(n^3)$ DP。

设 $f_{i,j}$ 为当前你有 $i$ 个点，高度为 $j$ 的方案数。转移直接考虑把一个树接到另一个树下边。

```cpp
f[1][1] = 1;
rep (i, 1, n) pre[1][i] = 1;
rep (i, 2, n) {
    rep (j, 2, i) {
        rep (k, 1, i - 1) {
            f[i][j] += f[i - k][j] * pre[k][j - 1];
            f[i][j] += pre[i - k][j - 1] * f[k][j - 1];
        }
    }
    rep (j, 1, n)
        pre[i][j] = pre[i][j - 1] + f[i][j];
}
Mint ans = 0;
rep (i, 1, n) {
    ans += f[n][i] * (i - 1);
}
```

考虑优化，这个dp本质上是第一维做加法卷积，第二维做 max 卷积。于是应该容易用 ntt 做到 O(n^2\log n)$。获得六十分。但实际上模数卡了你所以别往这个方向想。

就我们感觉一下这个深度是硬伤啊。其实我们是不是可以不计第二维呢？但问题是你取 max 啊！好像很难说你把他直接剁掉哎。

那我们换个方向，我觉得这个 DP 没有很多前途。

我有一计。你考虑你根本不管前面的了。你想 $f_{i}$ 表示 $n$ 个点的树里面深度为 $i$ 的方案数。

主要是你发现其实 $f$ 后几项是很规律的。你想一下能不能从后往前推。

你考虑你当前有一棵高为 $i$ 的树。然后你要把他的高度变矮。
